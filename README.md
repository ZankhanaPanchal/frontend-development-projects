# Frontend Development Projects

A collection of small web development exercises exploring HTML, CSS, page structure, navigation, forms, and interface layouts.

## Exercises

| Folder | Focus |
| --- | --- |
| `Coffee Project/` | A themed web page and visual layout practice |
| `Form/` | HTML forms and input fields |
| `List Infograhic/` | Information layouts and lists |
| `Position-Task/` | CSS positioning exercises |
| `navigation-bar/` | Navigation layout and styling |
| `registration form/` | Registration form user interface |

## Technologies
HTML and CSS. Check individual exercises for any additional technologies.

## How to view
Open a project folder and view its HTML file in a browser. Some examples may need local assets from the same folder.

## Screenshots
Add screenshots of your own exercises to a `screenshots/` folder, then link them here, for example:

## What I practiced
Semantic page structure, forms, CSS layouts, navigation, and interface presentation.

Accessibility checks, responsive design refinements, and JavaScript interactions.
